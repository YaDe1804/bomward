# Security policy

## Supported versions

bomward is pre-release. No version is supported for production use.

| Version | Supported |
| --- | --- |
| nothing released yet | no production support |

## Reporting a vulnerability

Report a vulnerability privately to Deniz Yayvan at
`deniz.yayvan@yadelabs.de`. Do not open a public issue for an undisclosed
vulnerability.

Include what you can of the following:

- a description of the issue
- the commit or version you ran
- a minimal SBOM or input that reproduces it, with secrets removed

Inert proof-of-concept files are welcome. Do not send live malware
samples. bomward's fixtures are synthetic on purpose.

There is no bug-bounty program.
